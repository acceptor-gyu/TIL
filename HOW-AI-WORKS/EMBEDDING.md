# 임베딩, 분포 가설, Word2Vec

## 임베딩이라는 발상
텍스트를 벡터 공산의 한 점으로 보내는 함수

### 임베딩(embedding)의 정의
f: 텍스트 -> Rn  
> 텍스트를 n차원의 벡터 공간으로 보내는 함수 f

텍스트 -> 실수 n개짜리 배열 하나  
입력이 단어든 문장이든 - 동일한 차원의 벡터로  

### 좋은 임베딩이 갖춰야 할 성질
의미가 비슷한 텍스트는 벡터 공간에서 `가까운 점`에 배치되어야 한다.
- "고양이" <-> "강아지" -> 거리 작음, 코사인 유사도 높음
- "고양이" <-> "경제 성장률" -> 거리 큼, 코사인 유사도 낮음

### 각 성분 숫자가 뜻하는 것
개별 숫자 하나에 "이 축은 감정"처럼 의미가 달린 것이 아니다.  
임베딩 함수가 학습으로 조정한 숫자들이다.
> 중요한 것은 개별 성분이 아니라 `벡터 전체의 위치`. 공간에서 다른 텍스트와 얼마나 가까운지가 의미를 반영한다.

### 가장 단순한 임베딩 - 원-핫
어휘 n개일 때 n차원 벡터, 자기 자리만 1 나머지 0
- 고양이 -> [1, 0, 0, 0, ...]
- 강아지 -> [0, 1, 0, 0, ...]
- 사과 -> [0, 0, 1, 0, ...]

> ### 원-핫의 결정적 한계
> 서로 다른 두 단어의 벡터는 1이 켜진 자리가 겹치지 않는다.  
> `내적 = 0, 코사인 유사도 = 0`  
> 
> 고양이 <-> 강아지도 0, 고양이 <-> 사과도 0. 모든 쌍이 똑같이 무관하다. 의미의 가까움이 전혀 반영되지 않는다.

원-핫처럼 손으로 규칙을 정해서는 "비슷한 의미 = 가까운 벡터"를 만들 수 없다.  
그 성질은 데이터와 학습으로부터 얻어야 한다. 출발점은 단어의 의미를 보는 방식. 즉 `분포 가설`이다.

## 분포 가설
단어는 함께 다니는 친구를 보면 알 수 있다. - 존 퍼스, 1957

### "XXX"라는 낯선 단어
- "아침에 XXX 한 잔을 마셨다."
- "따뜻한 XXX 마시고 싶다."
- "카페에서 XXX을 주문했다."
- "XXX에 설탕을 넣으면 더 달다."

사전이 없어도 음료라는 것을 알 수 있다. 문맥이 의미를 알려준다.

### 통계로 의미를 만든다는 발상
대량의 말뭉치에서 각 단어가 어떤 단어들과 얼마나 자주 함께 등장하는지를 수집하면 의미 정보를 얻을 수 있다.
- 대량 텍스트 -> 문맥 패턴 수집
- 비슷한 문맥 -> 비슷한 의미
- 비슷한 의미 -> 비슷한 벡터

### 왜 강력한 원칙인가
- 의미가 본질적으로 관계적 - "커피"의 의미는 관계망 속에 있음
- 언어를 불문하고 성립 - 한국어, 영어, 아럽어 공통
- 라벨 없이 데이터만으로 - 말뭉치가 클수록 정밀해짐

## Word2Vec
분포 가설을 예측 게임으로 바꿔 단어 벡터를 만드는 방법

### 문맥 관계를 예측 게임으로
말뭉치에서 "주변 단어와 가운데 단어 사이의 관계"를 맞히는 문제를 수백만 개 만들어 반복해서 푼다.  
모델이 문제를 풀면서 각 단의 벡터가 조금씩 다듬어진다.

### CBOW(Continuous Bag of Words)
주변 단어들이 주어졌을 때 `가운데 단어`를 맞힌다.  

"아침에 [?] 한 잔을 마셨다" -> 주변 문맥으로 [?] = "커피"를 예측
> 주변 여러 단어 -> 가운데 단어 하나

### Skip-gram
가운데 단어 하나가 주어졌을 때 `주변에 무엇이 오는지`를 맞힌다.

"커피" -> "아침에", "한 잔을", "마셨다"를 예측
> 가운데 단어 하나 -> 주변 단어 여러 개

### 학습이 진행되는 방식
- 처음: 모든 단어 벡터가 임의의 좌표
- 예측 -> 틀림 -> 벡터 조금 조정
- 이 과정을 수백만 ~ 수억 번 반복
- 반복이 쌓이면 문맥이 비슷한 단어끼리 가까워짐

### 학습이 끝나면
예측 게임은 좋은 벡터를 만들기 위한 수단이다.  
우리가 실제로 쓰는 것은 다듬어진 `단어 벡터`이다.
> "커피"와 "차"는 비슷한 문맥 관계를 수없이 맞히다 보니 자연스럽게 가까운 벡터로 수렴한다. 누가 라벨을 붙인 것이 아니다.

## 다음 과제: 문장 전체를 하나의 벡터로
Word2Vec은 `단어 하나 = 벡터 하나`이다.  
실제 검색, 비교는 단어가 아니라 `문장 전체를 벡터 하나로` 다루어야 한다.
