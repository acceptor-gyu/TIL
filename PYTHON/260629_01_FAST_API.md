# FAST API

## 개요

FastAPI는 Python 3.7+ 표준 타입 힌트를 기반으로 설계된 고성능 비동기 웹 프레임워크다. Starlette(ASGI 웹 toolkit)와 Pydantic(데이터 검증) 위에 구축되어 있으며, NodeJS나 Go 수준의 처리 성능을 Python에서 달성한다. 자동 API 문서 생성, 데이터 검증, 에디터 자동완성 등을 타입 힌트 선언 하나로 처리할 수 있다는 설계 철학이 핵심이다.

## 상세 내용

### FastAPI란 무엇인가

**등장 배경과 설계 철학**

FastAPI는 2018년 Sebastián Ramírez가 개발했다. 기존 파이썬 웹 프레임워크들이 비동기 I/O를 제대로 지원하지 못하거나, 데이터 검증과 문서화를 별도로 구성해야 한다는 문제를 해결하기 위해 탄생했다.

설계 철학은 "한 번의 선언으로 모든 것을 자동화"다. 타입 힌트 하나를 작성하면 다음 네 가지가 자동으로 처리된다.

1. 요청/응답 데이터 검증
2. Swagger UI / ReDoc 문서 자동 생성
3. 에디터 자동완성 및 타입 체크
4. OpenAPI 스키마 기반 클라이언트 코드 생성

**Flask, Django와의 비교**

| 항목 | FastAPI | Flask | Django |
|------|---------|-------|--------|
| 인터페이스 | ASGI | WSGI | WSGI (3.1부터 ASGI 지원) |
| 비동기 | 네이티브 지원 | 제한적 | 제한적 |
| 데이터 검증 | Pydantic 내장 | 직접 구현 | Form/Serializer |
| 자동 문서화 | 자동 생성 | 별도 라이브러리 | 별도 라이브러리 |
| 성능 | 매우 높음 | 보통 | 보통 |
| 적합한 사용처 | 고성능 API, ML 서빙 | 경량 서비스, 프로토타입 | 풀스택 웹앱 |

2026년 기준 대부분의 신규 Python API 프로젝트는 FastAPI를 기본 선택으로 채택한다. Microsoft, Uber, Netflix 등 주요 기업도 프로덕션에서 사용 중이다.

### 핵심 기반 기술

**Starlette (ASGI 웹 toolkit)**

FastAPI는 Starlette 위에 구축되어 있다. Starlette는 가볍고 빠른 ASGI 프레임워크/toolkit으로, FastAPI의 라우팅, 미들웨어, WebSocket, 백그라운드 태스크, 정적 파일 서빙 등 웹 레이어 전반을 담당한다.

```
요청 흐름:
Client → Uvicorn (ASGI 서버) → Starlette (라우팅/미들웨어) → FastAPI (의존성/검증) → 엔드포인트 함수
```

**Pydantic (데이터 검증 및 직렬화)**

Pydantic은 Python 타입 힌트를 기반으로 런타임 데이터 검증과 직렬화를 수행한다. Pydantic v2부터는 핵심 검증 로직을 Rust로 재작성하여 일부 케이스에서 v1 대비 최대 50배 빠른 파싱 성능을 달성했다.

```python
from pydantic import BaseModel, EmailStr
from datetime import date

class User(BaseModel):
    id: int
    name: str
    email: EmailStr       # 이메일 형식 자동 검증
    joined: date          # 날짜 형식 자동 파싱

# 잘못된 데이터 입력 시 자동으로 ValidationError 발생
user = User(id="not_int", name="Luke", email="invalid", joined="2026-01-01")
# => ValidationError: id는 int여야 함, email 형식 오류
```

Pydantic은 시작 시점(startup)에 타입 어노테이션을 검사하고 효율적인 validator를 컴파일해 캐싱한다. 요청마다 검증 함수를 새로 생성하지 않으므로 반복 요청에서도 성능이 유지된다.

**ASGI vs WSGI**

WSGI(Web Server Gateway Interface)는 PEP 333에서 정의된 동기 인터페이스다. 요청이 들어오면 응답이 반환될 때까지 다른 요청을 처리하지 않는 블로킹 I/O 모델이다.

ASGI(Asynchronous Server Gateway Interface)는 WSGI의 후속 표준으로, 비동기 I/O와 WebSocket, HTTP/2를 네이티브로 지원한다.

| 항목 | WSGI | ASGI |
|------|------|------|
| I/O 모델 | 동기(블로킹) | 비동기(논블로킹) |
| 동시성 방식 | 멀티스레드/멀티프로세스 | 이벤트 루프 + 코루틴 |
| WebSocket 지원 | 없음 | 있음 |
| HTTP/2 지원 | 없음 | 있음 |
| 대표 서버 | Gunicorn, uWSGI | Uvicorn, Hypercorn |

### 기본 사용법

**애플리케이션 생성과 라우팅 (Path Operation)**

```python
from fastapi import FastAPI

app = FastAPI()

@app.get("/")          # GET /
@app.post("/items/")   # POST /items/
@app.put("/items/{id}") # PUT /items/{id}
@app.delete("/items/{id}") # DELETE /items/{id}
```

데코레이터에 HTTP 메서드와 경로를 선언하면 FastAPI가 OpenAPI 스키마를 자동 생성한다.

**Path Parameter / Query Parameter**

```python
@app.get("/items/{item_id}")
async def read_item(
    item_id: int,           # Path Parameter - URL에서 추출
    q: str | None = None,   # Query Parameter - ?q=... 에서 추출
    skip: int = 0,          # Query Parameter - 기본값 있음
):
    return {"item_id": item_id, "q": q, "skip": skip}
```

타입 힌트만으로 파라미터 출처(경로 vs 쿼리)를 자동 구분하고, 타입 변환 및 검증도 자동 처리된다.

**Request Body와 Pydantic 모델**

```python
from pydantic import BaseModel

class Item(BaseModel):
    name: str
    price: float
    is_offer: bool = False

@app.post("/items/")
async def create_item(item: Item):  # Pydantic 모델을 파라미터로 선언
    return item
```

Pydantic 모델을 파라미터로 선언하면 FastAPI는 요청 body에서 JSON을 읽어 자동 검증한다.

**Response Model과 status code**

```python
@app.post("/items/", response_model=Item, status_code=201)
async def create_item(item: Item):
    return item
```

`response_model`을 지정하면 응답 데이터를 해당 모델로 필터링하여 직렬화하고, 문서에도 반영된다. 내부 필드(비밀번호 등)가 응답에 포함되는 실수를 방지할 수 있다.

### 비동기 처리

**async / await 와 코루틴**

파이썬의 async/await는 코루틴 기반 비동기 처리 모델이다. 코루틴은 실행을 일시 중지하고 제어권을 이벤트 루프에 넘길 수 있는 함수다.

```python
import asyncio

async def fetch_data():
    await asyncio.sleep(1)  # I/O 대기 동안 이벤트 루프로 제어권 반환
    return {"data": "result"}
```

`await` 키워드를 만나면 해당 코루틴은 완료를 기다리는 동안 이벤트 루프로 제어권을 넘긴다. 이벤트 루프는 그동안 다른 코루틴을 실행하여 CPU를 낭비하지 않는다.

**동기(def) vs 비동기(async def) 엔드포인트 동작 차이**

FastAPI는 두 가지 방식의 엔드포인트를 모두 지원하며, 내부 동작 방식이 다르다.

```python
# 비동기 엔드포인트 - 이벤트 루프에서 직접 실행
@app.get("/async-items/")
async def read_items_async():
    await some_async_db_call()
    return items

# 동기 엔드포인트 - 별도 스레드풀에서 실행
@app.get("/sync-items/")
def read_items_sync():
    some_blocking_db_call()
    return items
```

`def`로 정의된 동기 엔드포인트는 이벤트 루프를 블로킹하지 않기 위해 FastAPI가 자동으로 `run_in_executor`를 통해 외부 스레드풀에서 실행한다. 단, `async def` 안에서 블로킹 코드를 실행하면 이벤트 루프 전체가 블로킹되므로 주의해야 한다.

| 상황 | 권장 방식 |
|------|---------|
| 비동기 라이브러리 사용 (aiomysql, httpx 등) | `async def` |
| 동기 라이브러리 사용 (requests, psycopg2 등) | `def` (스레드풀 자동 위임) |
| CPU 집약적 작업 | `def` + ProcessPoolExecutor 수동 위임 |

**이벤트 루프와 동시성**

FastAPI(Uvicorn)는 단일 스레드에서 이벤트 루프를 실행한다. 동시성(Concurrency)은 있지만 병렬성(Parallelism)은 없다. I/O 대기 시간 동안 다른 요청을 처리할 수 있으므로 I/O 바운드 워크로드에서 뛰어난 성능을 발휘한다.

CPU 바운드 작업의 병렬 처리가 필요하다면 Gunicorn + Uvicorn 워커 조합으로 멀티프로세스를 활용한다.

### 의존성 주입 (Dependency Injection)

**Depends 활용**

FastAPI의 의존성 주입 시스템은 `Depends`를 통해 동작한다. 의존성 함수는 엔드포인트가 호출되기 전에 실행되어 값을 제공한다.

```python
from fastapi import Depends, FastAPI, HTTPException
from fastapi.security import OAuth2PasswordBearer

oauth2_scheme = OAuth2PasswordBearer(tokenUrl="token")

async def get_current_user(token: str = Depends(oauth2_scheme)):
    user = decode_token(token)
    if not user:
        raise HTTPException(status_code=401, detail="Invalid token")
    return user

@app.get("/users/me")
async def read_users_me(current_user: User = Depends(get_current_user)):
    return current_user
```

**공통 로직 재사용과 테스트 용이성**

의존성은 계층 구조(graph)를 형성할 수 있다. 의존성이 다른 의존성에 의존하는 구조도 FastAPI가 자동으로 해결한다.

```python
# DB 세션 의존성
async def get_db():
    db = SessionLocal()
    try:
        yield db  # yield로 컨텍스트 관리
    finally:
        db.close()

# 인증 + DB를 함께 주입
@app.get("/items/")
async def read_items(
    db: Session = Depends(get_db),
    current_user: User = Depends(get_current_user)
):
    return db.query(Item).all()
```

테스트 시에는 `app.dependency_overrides`를 통해 의존성을 모킹 함수로 교체할 수 있어 테스트 격리가 용이하다.

### 데이터 검증과 직렬화

**Pydantic 모델 기반 자동 검증**

```python
from pydantic import BaseModel, Field, validator

class Item(BaseModel):
    name: str = Field(..., min_length=1, max_length=100)
    price: float = Field(..., gt=0)           # 0보다 커야 함
    tax: float | None = Field(None, ge=0)     # None이거나 0 이상

    @validator("name")
    def name_must_not_contain_space(cls, v):
        if " " in v:
            raise ValueError("이름에 공백 불가")
        return v
```

검증 실패 시 FastAPI는 자동으로 422 Unprocessable Entity 응답을 반환하고, 어떤 필드에서 어떤 오류가 발생했는지 상세 메시지를 제공한다.

**자동 문서화 (Swagger UI / ReDoc, OpenAPI)**

애플리케이션 실행 후:
- `http://localhost:8000/docs` - Swagger UI (브라우저에서 직접 API 호출 가능)
- `http://localhost:8000/redoc` - ReDoc 문서
- `http://localhost:8000/openapi.json` - OpenAPI 스키마 JSON

코드 변경 시 문서가 자동으로 업데이트되므로 별도 문서 관리가 불필요하다.

### 미들웨어와 예외 처리

**미들웨어 등록**

미들웨어는 모든 요청/응답을 가로채 공통 로직을 적용한다.

```python
from fastapi.middleware.cors import CORSMiddleware
import time

# CORS 미들웨어 등록
app.add_middleware(
    CORSMiddleware,
    allow_origins=["https://example.com"],
    allow_methods=["*"],
    allow_headers=["*"],
)

# 커스텀 미들웨어 - 요청 처리 시간 측정
@app.middleware("http")
async def add_process_time_header(request, call_next):
    start_time = time.time()
    response = await call_next(request)
    process_time = time.time() - start_time
    response.headers["X-Process-Time"] = str(process_time)
    return response
```

**예외 핸들러와 HTTPException**

```python
from fastapi import HTTPException
from fastapi.responses import JSONResponse

# HTTPException 발생
@app.get("/items/{item_id}")
async def read_item(item_id: int):
    if item_id not in db:
        raise HTTPException(status_code=404, detail="Item not found")
    return db[item_id]

# 전역 예외 핸들러 등록
@app.exception_handler(404)
async def not_found_handler(request, exc):
    return JSONResponse(status_code=404, content={"message": "리소스를 찾을 수 없습니다"})
```

### 인증과 보안

**OAuth2, JWT 기반 인증**

```python
from fastapi.security import OAuth2PasswordBearer, OAuth2PasswordRequestForm
from jose import JWTError, jwt

SECRET_KEY = "your-secret-key"
ALGORITHM = "HS256"

oauth2_scheme = OAuth2PasswordBearer(tokenUrl="token")

@app.post("/token")
async def login(form_data: OAuth2PasswordRequestForm = Depends()):
    user = authenticate_user(form_data.username, form_data.password)
    if not user:
        raise HTTPException(status_code=401)
    access_token = jwt.encode({"sub": user.username}, SECRET_KEY, algorithm=ALGORITHM)
    return {"access_token": access_token, "token_type": "bearer"}

async def get_current_user(token: str = Depends(oauth2_scheme)):
    try:
        payload = jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM])
        username = payload.get("sub")
    except JWTError:
        raise HTTPException(status_code=401)
    return get_user(username)
```

**Security 유틸리티**

FastAPI는 OpenAPI 보안 스키마를 모두 지원한다.

- `OAuth2PasswordBearer` - Bearer 토큰 방식
- `OAuth2AuthorizationCodeBearer` - Authorization Code 방식
- `HTTPBasic` - HTTP Basic Auth
- `APIKeyHeader`, `APIKeyQuery`, `APIKeyCookie` - API Key 방식

보안 의존성을 선언하면 Swagger UI의 Authorize 버튼에 자동 반영되어 문서에서 직접 인증 테스트가 가능하다.

## 핵심 정리

- FastAPI는 Starlette(ASGI) + Pydantic(데이터 검증)을 기반으로 하며, Python 타입 힌트 하나로 검증, 문서화, 에디터 지원을 모두 자동 처리한다.
- ASGI 기반이므로 단일 이벤트 루프에서 비동기 I/O를 처리하여 높은 동시성을 달성한다. `async def`는 이벤트 루프에서, `def`는 스레드풀에서 실행된다.
- Dependency Injection(`Depends`)으로 인증, DB 세션, 공통 파라미터 추출 등의 공통 로직을 재사용하고 테스트 시 쉽게 모킹할 수 있다.
- Pydantic v2는 Rust 기반 검증 코어로 성능이 크게 향상되었으며, `response_model` 지정으로 내부 데이터 노출을 방지할 수 있다.
- 자동 생성된 Swagger UI(`/docs`)에서 인증 포함 직접 API 호출 테스트가 가능하므로 개발 생산성이 높다.

## 기술적 한계와 보완 전략

| 한계 | 보완 전략 |
|------|---------|
| CPU 바운드 작업에서 이벤트 루프 블로킹 | `run_in_executor` + ProcessPoolExecutor 사용 |
| 단일 프로세스로 멀티코어 미활용 | Gunicorn + Uvicorn 워커 조합으로 멀티프로세스 운영 |
| ORM 비동기 지원 부재 (SQLAlchemy 동기) | SQLAlchemy 2.0 async 세션 또는 Tortoise ORM 활용 |
| 대용량 파일 업로드 시 메모리 이슈 | 스트리밍 업로드 + 청크 처리 방식 적용 |
| 글로벌 상태 공유 어려움 | Redis / 외부 상태 저장소 활용 |

## 키워드

- **FastAPI**: Python 표준 타입 힌트 기반의 고성능 비동기 웹 프레임워크. Starlette와 Pydantic 위에 구축됨.
- **ASGI**: Asynchronous Server Gateway Interface. 비동기 I/O, WebSocket, HTTP/2를 지원하는 Python 웹 서버 인터페이스 표준. WSGI의 후속.
- **Starlette**: FastAPI의 웹 레이어를 담당하는 경량 ASGI 프레임워크/toolkit. 라우팅, 미들웨어, WebSocket을 제공.
- **Pydantic**: Python 타입 힌트 기반 데이터 검증 및 직렬화 라이브러리. v2부터 Rust 기반 코어로 성능 대폭 향상.
- **async/await**: Python의 코루틴 기반 비동기 처리 문법. `await` 지점에서 이벤트 루프로 제어권을 반환하여 논블로킹 I/O를 구현.
- **Dependency Injection**: `Depends`를 통해 엔드포인트에 공통 로직(인증, DB 세션 등)을 주입하는 패턴. 의존성 계층 구조를 자동 해결.
- **OpenAPI**: REST API를 기술하는 개방형 표준 스펙(구 Swagger). FastAPI는 이를 자동 생성하여 Swagger UI와 ReDoc을 제공.
- **Uvicorn**: ASGI 프로토콜을 구현한 경량 Python 비동기 서버. uvloop 기반으로 높은 I/O 성능을 발휘하며 FastAPI의 기본 서버로 사용.
- **Type Hint**: PEP 484에서 도입된 Python 변수/함수 타입 어노테이션 문법. FastAPI는 이를 기반으로 검증, 문서화, 직렬화를 자동 처리.
- **Coroutine**: `async def`로 정의된 비동기 함수. 실행 도중 `await` 지점에서 일시 중단하고 이벤트 루프에 제어권을 반환할 수 있는 객체.
